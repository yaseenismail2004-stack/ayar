# 💜 أيار — نظام إدارة الصيدلية

نظام بسيط وأنيق لإدارة الصيدلية بتصميم **زجاجي بأسلوب Apple** وألوان **بنفسجي وأبيض**، وواجهة عربية كاملة.

## المميزات
- **الكاشير (POS):** مسح الباركود بالقارئ أو الكاميرا، أو البحث بالاسم. خصم، وحساب الباقي، وطباعة فاتورة حرارية (80mm). يصرف من الدفعة الأقرب انتهاءً أولاً (FEFO) ولا يبيع المنتجات المنتهية.
- **المنتجات:** إضافة المنتج بالباركود بثلاث طرق: **مسح/إدخال يدوي**، أو **توليد رمز تلقائي** (EAN-13 داخلي)، أو **بدون كود**. ومعاينة الباركود وطباعة الملصقات.
- **أكثر من تاريخ صلاحية للمنتج نفسه:** لكل منتج دفعات، ولكل دفعة رقم وتاريخ انتهاء وكمية وسعر شراء.
- **استلام بضاعة:** امسح الكود؛ إذا كان المنتج مسجّلاً تُضاف له دفعة بتاريخ جديد، وإن لم يكن مسجّلاً يُفتح نموذج منتج جديد.
- **الجرد:** جرد فعلي لكل دفعة (ومسح الباركود يزيد العدّ بمقدار +1)، مع عرض الفروقات وسجل للجرد. وفيه أيضاً تقرير الصلاحية وإتلاف المنتهي وقيمة المخزون بسعر الشراء وسعر البيع.
- **المبيعات:** فلترة حسب التاريخ، والربح التقديري، وإعادة طباعة الفاتورة، وإرجاع الفاتورة مع إعادة الكميات إلى المخزون.
- **المستخدمين والصلاحيات:** تسجيل دخول لكل موظف بثلاث صلاحيات: **مدير** (كل الأقسام)، و**صيدلاني** (كل الأقسام عدا المستخدمين والإعدادات)، و**كاشير** (الكاشير والزبائن والمبيعات فقط، بدون إرجاع فواتير أو رؤية الأرباح). كل فاتورة تُسجَّل باسم الموظف الذي باعها. كلمات المرور تُخزَّن مشفّرة (SHA-256).
- **المشتريات والموردين:** سجل للموردين، وفواتير شراء بالباركود (لكل سطر رقم دفعة وتاريخ انتهاء وكمية وسعر) تُضاف للمخزون تلقائياً وتحدّث سعر الشراء. دفع كامل أو جزئي أو آجل، وكشف حساب لكل مورد مع تسجيل الدفعات.
- **الزبائن والديون:** البيع بالآجل من الكاشير (كاملاً أو مع دفعة مقدمة)، وكشف حساب لكل زبون مع رصيد تراكمي، وتسجيل التسديدات، وطباعة الكشف، وتذكير عبر واتساب.
- **لوحة تحكم:** مبيعات اليوم، ومخطط لآخر 7 أيام، وتنبيهات الصلاحية والنواقص.
- **6 ثيمات:** بنفسجي أيار، ولافندر، وأرجواني ملكي، وأوركيد، وأبيض نقي، وليلي.
- **موقع عرض المنتجات (`/store`):** صفحة عامة للزبائن فيها بحث وأصناف وحالة التوفر وزر طلب عبر واتساب، بدون عرض أسعار الشراء.
- **نسخ احتياطي:** تصدير البيانات واستيرادها بملف JSON.

## التشغيل
يحتاج فقط [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث)، ولا توجد أي مكتبات للتثبيت:

```bash
npm start
```
- لوحة الإدارة: http://localhost:3000
- موقع العرض للزبائن: http://localhost:3000/store

**أول دخول:** المستخدم `admin` وكلمة المرور `1234`، وسيطلب منك النظام تغييرها (6 أحرف على الأقل). بعدها أضف الموظفين من قسم «المستخدمين».

تُحفظ البيانات في `data/db.json`. وإذا أردت طبقة حماية إضافية تطلب كلمة مرور قبل فتح صفحة الإدارة نفسها:
```bash
ADMIN_PASSWORD=كلمة-سر-قوية npm start
```
صفحة المتجر تبقى عامة.

## 🔒 الأمان
- **تسجيل الدخول يتحقق منه الخادم:** كلمات المرور مشفّرة بـ `scrypt` مع ملح عشوائي، وكل جلسة لها رمز عشوائي صالح 12 ساعة.
- **حماية البيانات:** أي طلب للبيانات بدون تسجيل دخول يُرفض. كلمات المرور لا تُرسل للمتصفح أبداً.
- **الصلاحيات على الخادم:** إدارة المستخدمين للمدير فقط، والإعدادات لا يغيّرها إلا المدير.
- **الحماية من التخمين:** قفل لمدة 15 دقيقة بعد 5 محاولات دخول خاطئة.
- **رؤوس أمان:** Content-Security-Policy و nosniff، مع تنظيف الصور والمدخلات لمنع حقن الشيفرات (XSS) ومنع الوصول لملفات الخادم.
- **مهم عند النشر على الإنترنت:** شغّل النظام خلف **HTTPS** (مثل Caddy أو Nginx أو Cloudflare)، وخذ نسخة احتياطية دورية من `data/db.json`.

## 📱 الموبايل والآيباد
- **الموبايل:** شريط تبويبات سفلي بأسلوب iOS، والجداول تتحول إلى بطاقات، والنوافذ تفتح من الأسفل، والسلة في الكاشير زر عائم.
- **الآيباد:** شريط جانبي مختصر بالأيقونات، ويعمل بالوضعين العمودي والأفقي.
- **أجهزة اللمس:** أزرار بحجم مناسب للإصبع، ولا يحصل تكبير مزعج عند الكتابة على iPhone.
- **تثبيت كتطبيق:** من Safari اختر «مشاركة ← إضافة إلى الشاشة الرئيسية» ليعمل كتطبيق بملء الشاشة.

> يمكن أيضاً فتح `public/index.html` مباشرة بدون خادم، وفي هذه الحالة تُحفظ البيانات في المتصفح فقط.

## قارئ الباركود
أي قارئ باركود USB أو Bluetooth يعمل مباشرة، لأنه يكتب الرمز ثم يضغط Enter. كما يمكن المسح بكاميرا الهاتف أو اللابتوب من زر الكاميرا.
