# 💜 أيار — نظام إدارة الصيدلية

نظام بسيط وأنيق لإدارة الصيدلية بتصميم **زجاجي بأسلوب Apple** وألوان **بنفسجي وأبيض**، وواجهة عربية كاملة. يعمل على **Cloudflare Workers + D1**، ويشتغل على الكمبيوتر والآيباد والموبايل.

- **موقع الزبائن:** `https://ayarpharmacy.online/`
- **لوحة الإدارة:** `https://ayarpharmacy.online/admin`

## المميزات
- **الكاشير (POS):** مسح الباركود بالقارئ أو الكاميرا، أو البحث بالاسم. خصم، وحساب الباقي، والبيع بالآجل، وطباعة فاتورة حرارية (80mm). البيع يتم على الخادم ويصرف من الدفعة الأقرب انتهاءً أولاً (FEFO)، ولا يمكن بيع نفس الكمية من جهازين بنفس الوقت.
- **المنتجات:** إضافة المنتج بالباركود بثلاث طرق: مسح/إدخال يدوي، أو توليد رمز تلقائي، أو بدون كود. وطباعة ملصقات الباركود.
- **أكثر من تاريخ صلاحية للمنتج نفسه:** لكل دفعة رقم وتاريخ انتهاء وكمية وسعر شراء.
- **الجرد:** جرد فعلي بالباركود مع الفروقات وسجل للجرد، وتقرير الصلاحية، وإتلاف المنتهي، وقيمة المخزون.
- **المشتريات والموردين:** فواتير شراء تُضاف للمخزون تلقائياً، ودفع كامل أو جزئي أو آجل، وكشف حساب لكل مورد.
- **الزبائن والديون:** البيع بالآجل، وكشف حساب لكل زبون، وتسجيل التسديدات، وتذكير عبر واتساب.
- **المبيعات:** فلترة حسب التاريخ، والأرباح، وإعادة طباعة الفاتورة، وإرجاع الفاتورة.
- **المستخدمين والصلاحيات:** مدير، وصيدلاني، وكاشير، والصلاحيات يفرضها الخادم.
- **مزامنة بين الأجهزة:** كل جهاز يرى تغييرات الأجهزة الأخرى خلال ثوانٍ. وإذا عدّل جهازان نفس السجل بنفس الوقت، لا يضيع شيء بصمت.
- **6 ثيمات**، وتثبيت النظام كتطبيق على الآيباد والموبايل.

## 🚀 النشر على Cloudflare (ayarpharmacy.online)

### 1) نقل الدومين إلى Cloudflare (مرة واحدة)
الدومين مسجّل في **Spaceship**، وخوادم الأسماء الحالية هي `launch1/launch2.spaceship.net`.
1. افتح [dash.cloudflare.com](https://dash.cloudflare.com)، ثم **Add a domain**، واكتب `ayarpharmacy.online` واختر الخطة **Free**.
2. سيعطيك Cloudflare خادمَي أسماء (Nameservers)، مثل `xxx.ns.cloudflare.com`.
3. في Spaceship: افتح الدومين، ثم **Nameservers**، ثم **Custom**، والصق خادمَي Cloudflare واحفظ.
4. انتظر حتى تصبح حالة الدومين في Cloudflare **Active**. يأخذ عادةً من دقائق إلى بضع ساعات.

### 2) تجهيز المشروع على الكمبيوتر
يحتاج [Node.js](https://nodejs.org) الإصدار 22 أو أحدث.
```bash
git clone https://github.com/yaseenismail2004-stack/ayar.git
cd ayar
npm install
npx wrangler login              # يفتح المتصفح لتسجيل الدخول إلى Cloudflare
npx wrangler d1 create ayar-db  # ينشئ قاعدة البيانات
```
انسخ قيمة `database_id` التي تظهر، وضعها في ملف `wrangler.toml` مكان الأصفار.

### 3) ربط الدومين والنشر
في `wrangler.toml` احذف علامة `#` من أسطر `routes`، ثم نفّذ:
```bash
npx wrangler deploy
```
افتح `https://ayarpharmacy.online/admin` وادخل بالمستخدم `admin` وكلمة المرور `1234`، وسيطلب منك النظام تغييرها فوراً.

> الجداول تُنشأ تلقائياً عند أول تشغيل، فلا حاجة لأي أوامر إضافية لقاعدة البيانات.

**للتحديث لاحقاً:** نفّذ `git pull` ثم `npx wrangler deploy`. ويمكن أيضاً ربط المستودع من لوحة Cloudflare (**Workers ← Settings ← Builds**) ليُنشر تلقائياً عند كل دفع للفرع الرئيسي.

### الخطة المجانية تكفي؟
نعم لصيدلية واحدة: 100,000 طلب يومياً، وقاعدة بيانات حتى 500MB. النظام مصمم ليستخدم عدداً قليلاً من الاستعلامات في كل طلب. وإذا كبر العمل كثيراً، فخطة **Workers Paid** بـ 5$ شهرياً.

### 💾 النسخ الاحتياطي
- **Time Travel في D1:** يمكن استرجاع قاعدة البيانات لأي لحظة خلال آخر 7 أيام (مجاناً):
  `npx wrangler d1 time-travel restore ayar-db --timestamp=...`
- **نسخة كاملة يدوية:**
  `npx wrangler d1 export ayar-db --remote --output=backup.sql`
- **من داخل النظام:** الإعدادات ← تصدير نسخة (ملف JSON).

## 💻 التطوير المحلي
```bash
npm start        # خادم Node.js مع SQLite محلي (data/ayar.sqlite)
npm run cf:dev   # أو: محاكاة Cloudflare الحقيقية محلياً (wrangler + D1 محلي)
```
- **موقع الزبائن:** http://localhost:3000
- **لوحة الإدارة:** http://localhost:3000/admin

الخادمان يستخدمان نفس الشيفرة (`src/core.js`)، فما يعمل محلياً يعمل على Cloudflare.

## 🗂️ هيكل المشروع
```
src/core.js      منطق الخادم: المصادقة، المزامنة، البيع، المستخدمين، المتجر
src/worker.js    نقطة الدخول على Cloudflare Workers
server.js        خادم التطوير المحلي (Node.js + SQLite)
wrangler.toml    إعدادات Cloudflare
public/          الواجهة: index.html (المتجر)، admin.html (الإدارة)، js، css
```

## 🔒 الأمان
- **تسجيل الدخول:** يتحقق منه الخادم. كلمات المرور مشفّرة بـ **PBKDF2-SHA256** مع ملح عشوائي، والجلسات محفوظة في قاعدة البيانات كبصمة مشفّرة فقط.
- **الصلاحيات على الخادم:** الكاشير لا يستطيع تعديل المنتجات أو الأسعار أو حذف أي شيء. الإعدادات والمستخدمين للمدير فقط.
- **الحماية من التخمين:** قفل لمدة 15 دقيقة بعد 5 محاولات دخول خاطئة.
- **رؤوس أمان:** Content-Security-Policy، مع تنظيف الصور والمدخلات لمنع حقن الشيفرات (XSS).
- **HTTPS:** يوفّره Cloudflare تلقائياً.

## 📱 الموبايل والآيباد
- **الموبايل:** شريط تبويبات سفلي بأسلوب iOS، والجداول تتحول إلى بطاقات، والسلة في الكاشير لوح منبثق.
- **الآيباد:** شريط جانبي مختصر، ويعمل بالوضعين العمودي والأفقي.
- **تثبيت كتطبيق:** زر «تثبيت» داخل التطبيق (أندرويد بضغطة، والآيفون يعرض الخطوات: مشاركة ← إضافة إلى الشاشة الرئيسية).
- **إحساس تطبيق:** شاشة افتتاح، انتقالات ناعمة، اسحب للتحديث، اسحب اللوح للأسفل لإغلاقه، اهتزاز خفيف، عنوان كبير ينكمش، ووضع كاشير بملء الشاشة.
- **اختصارات الأيقونة:** ضغطة مطوّلة على أيقونة التطبيق ← بيع جديد، إضافة منتج، الجرد، التقارير.

## 📴 العمل بدون إنترنت
- واجهة التطبيق محفوظة على الجهاز (`public/sw.js`) فيفتح حتى بدون اتصال، مع آخر نسخة من البيانات (IndexedDB).
- **البيع مستمر عند الانقطاع:** الفاتورة تأخذ رقماً مؤقتاً (م1، م2…) وتُحفظ في صندوق صادر على الجهاز، وتُرفع تلقائياً عند عودة الاتصال برقمها الرسمي وتاريخ البيع الفعلي.
- الخادم يمنع تكرار الفاتورة إن وصلت مرتين، والمخزون يُخصم مرة واحدة فقط.
- عند تحديث الواجهة: غيّر `VERSION` في `public/sw.js` حتى تُحدَّث النسخة المحفوظة على الأجهزة.
